# Sunshine Surveyors

Website and working folder for **Sunshine Surveyors**, a trading name of Brimbank Spatial (ABN 34 697 779 856), serving Brimbank and Melbourne's western suburbs.

- **Live site:** https://sunshinesurveyors.au (Netlify, auto-deploys from `main`)
- **Where things stand:** [`docs/status.md`](docs/status.md)
- **For AI assistants:** start with [`CLAUDE.md`](CLAUDE.md)

## Layout
```
site/        the public website (only folder Netlify publishes)
docs/        project knowledge: status, business, roadmap, tech, marketing, people
  decisions/ one file per decision
  research/  competitor notes
  archive/   superseded material
CHANGELOG.md session-by-session log
```

## Editing the site
Edit HTML in `site/`, open a pull request, check the Netlify deploy preview, then merge to `main` to go live.
